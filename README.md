# 多维表格 CSV 导出（边栏插件）

将飞书多维表格当前数据表导出为 CSV。超链接字段输出「显示文字 空格 原始链接」（如 `我的主页 https://example.com`），显示文字与链接相同时只输出一次。

界面自动跟随飞书语言（中文 / English），适配深浅色主题；数据全部在浏览器本地生成，不外发任何请求。

## 使用

1. 本地调试：`npm i` → `npm run dev`，把 `http://localhost:5173/` 填入多维表格「插件 → 自定义插件 → +新增插件」。
2. 部署：`npm run build`，将 `dist/` 静态部署（或直接把 `dist/` 作为插件运行地址来源）。
3. 插件内选择数据表（默认当前激活表）与字段（默认全选），点「导出 CSV」。

## 行为说明

- CSV：UTF-8 带 BOM（Excel 打开中文不乱码）；含逗号/引号/换行的单元格按 CSV 规范转义。
- 超链接：`FieldType.Url` 字段与文本字段内嵌链接片段，均输出 `显示文字 空格 原始链接`；空值输出空串。
- **字段顺序**：字段勾选默认顺序与 CSV 列顺序均按视图内的列顺序（`view.getFieldMetaList()`，SDK 标注「有序」），与表格里看到的一致。
- 数据读取走批量分页接口 `getRecordsByPage`（官方已弃用 `getRecords`），导出时实时拉取。
- 数据变化监听：表增删/切换表/字段变化 → 防抖重建表单；记录变化 → 状态条提示同步（导出取实时数据，不打断勾选）。
- 深浅色主题经 `bitable.bridge.getTheme()` / `onThemeChange()` 适配；垂直布局，自适应面板宽度（宿主最小 410px）。
- 无路由（不使用 history 路由）；无任何外发请求，CSV 在浏览器本地生成。

## 文件保存策略（多策略自适应）

插件 iframe 在部分环境（尤其浏览器版飞书）会被沙箱拦截「下载动作」与「弹窗动作」，而 SDK 无任何宿主级保存 API。因此保存走多策略瀑布，前一个被拦截自动降级：

1. `showSaveFilePicker` 系统原生保存对话框
2. `window.open` 新标签页导航（可探测是否被拦）
3. `<a download>` 传统下载
4. 剪贴板复制（可粘贴进 Excel 另存）
5. 右键指引（唯一必通路径：右键按钮 →「链接另存为」或「在新标签页打开」）

导出后结果面板显示记录数、字段数、文件大小与文件名，并附「复制 CSV 内容」兜底按钮。受限环境下的提示语会自动说明当前可用的保存方式。

## 目录

```
src/core/       纯函数：单元格格式化（format.ts）、CSV 组装（csv.ts）、取值归一化（values.ts）
src/sdk/        SDK 取数层（批量分页 + 视图有序字段），带编译期类型校验
src/            UIBuilder 表单、多策略保存（download.ts）、结果面板（resultPanel.ts）、
                中英 i18n（i18n.ts）、主题适配（theme.ts）
tests/          vitest 单元测试（43 条，含超链接硬性规则）
```

## 已知取舍

- 附件只导出文件名（附件下载链接需签名，属后续扩展）。
- 关联字段导出被引用记录的文本，不含记录链接。
- 浏览器版飞书若拦截插件内下载/弹窗，需用右键保存或复制兜底（见上文保存策略）；桌面客户端通常无此限制。
- xlsx/JSON 导出、按视图筛选导出属后续扩展。
