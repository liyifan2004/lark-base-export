# 多维表格 CSV 导出（边栏插件）

将飞书多维表格当前数据表导出为 CSV。超链接字段输出「显示文字 空格 原始链接」（如 `我的主页 https://example.com`），显示文字与链接相同时只输出一次。

## 使用

1. 本地调试：`npm i` → `npm run dev`，把 `http://localhost:5173/` 填入多维表格「插件 → 自定义插件 → +新增插件」。
2. 部署：`npm run build`，将 `dist/` 静态部署（或直接把 `dist/` 作为插件运行地址来源）。
3. 插件内选择数据表（默认当前激活表）与字段（默认全选，留空导出全部），点「导出 CSV」。

## 行为说明

- CSV：UTF-8 带 BOM（Excel 打开中文不乱码）；含逗号/引号/换行的单元格按 CSV 规范转义。
- 超链接：`FieldType.Url` 字段与文本字段内嵌链接片段，均输出 `显示文字 空格 原始链接`；空值输出空串。
- 数据读取走批量分页接口 `getRecordsByPage`（官方已弃用 `getRecords`），导出时实时拉取。
- 数据变化监听：表增删/切换表/字段变化 → 防抖重建表单；记录变化 → 状态条提示同步（导出取实时数据，不打断勾选）。
- 深浅色主题经 `bitable.bridge.getTheme()` / `onThemeChange()` 适配；垂直布局，自适应面板宽度（宿主最小 410px）。
- 字段默认全选，顺序与 CSV 列顺序均按**视图内的列顺序**（`view.getFieldMetaList()`，有序）。
- 浏览器环境若自动下载被拦截，导出后表单下方有「下载」按钮兜底（新标签页导航方式，右键 → 在新标签页打开亦可）。
- 无路由（不使用 history 路由）；无任何外发请求，CSV 在浏览器本地生成。

## 目录

```
src/core/    纯函数：单元格格式化（format.ts）、CSV 组装（csv.ts），可脱离 SDK 单测
src/sdk/     SDK 取数层（批量分页），带编译期类型校验
src/         UIBuilder 表单、主题适配、浏览器下载
tests/       vitest 单元测试（39 条，含超链接硬性规则）
```

## 测试

`npm test`（vitest）。超链接输出规则、CSV 转义、BOM、文件名均有用例。

## 已知取舍

- 附件只导出文件名（附件下载链接需签名，属后续扩展）。
- 关联字段导出被引用记录的文本，不含记录链接。
- xlsx/JSON 导出、按视图筛选导出、i18n 属后续扩展。
